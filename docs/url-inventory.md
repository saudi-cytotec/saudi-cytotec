## 2. Domain history discovered

Previous generations of content on the domain included:

| Era | Evidence | Handling |
|---|---|---|
| 2018–2021 Blogger auto-scraper | archived year-based junk paths | **410** |
| WordPress medical-seller era | `/cytotec-saudi-arabia/`, `/سايتوتك_في_السعوديه/`, `/سايتوتك/`, city pages, phone-number spam | **301** only where an educational equivalent exists; **410** for spam/buyer-intent families without a safe equivalent |
| Static HTML era | `/about.html`, `/contact.html`, `/privacy-policy.html`, `/category-care.html` | **301** to the matching live page |

## 3. Redirect decisions (principles)

- **301 only where an equivalent, relevant replacement exists.**
- **410** for buyer-intent spam, phone-number slugs, feed endpoints, and scraper-era junk.
- Never blanket-redirect unknown 404s to the homepage.
- Saudi generic geographic legacy URLs now resolve to the Saudi hub at `/service-areas`.
- Drug-name and definition intent can resolve to `/what-is-cytotec` when the old URL was informational rather than geographic.
- Usage/how-to legacy URLs resolve to `/medical-uses` rather than any transactional path.

## 4. What must never regress

- The current public sitemap coverage of 141 URLs.
- Self-referencing canonicals emitted by `src/components/Seo.tsx`.
- Inclusion of public educational pages and exclusion of `/admin`, `/api`, and `/search` from crawl targets where appropriate.
- Schema policy: `Article`, `MedicalWebPage`, `FAQPage`, `CollectionPage`, `BreadcrumbList`, `WebSite`, `Organization` only as truthful informational markup — **never** `Drug`, `Product`, `Offer`, `Review`, or `AggregateRating`.
- The Saudi hub / city-page architecture must remain informational only: no sales, prices, delivery, fake providers, or unsafe dosing.

## 5. Regression checks

- `npm run build` regenerates redirects, sitemap, and SEO audit.
- `node scripts/urlParity.mjs` confirms no previously baselined live URL was lost.
- `node scripts/urlParity.mjs --update-baseline` is used after intentional sitemap growth.
- `node scripts/auditSeo.mjs` verifies robots, schema, redirect integrity, sitemap presence, internal-link validity, and image references.
